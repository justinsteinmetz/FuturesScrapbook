# Futures Scrapbook

A collage-style grammar game on the four ways of talking about the future in English, for use in lessons.

**Play it:** https://justinsteinmetz.github.io/FuturesScrapbook/

## What it covers

- **will**: decisions made now, offers, promises and opinions
- **going to**: earlier plans and predictions you can see coming
- **present progressive**: fixed arrangements with a time
- **present simple**: timetables and schedules

Each form has a short lesson scrap followed by a six-question challenge. A fifth scrap, the decider, mixes all four forms. Beat every scrap to unlock the boss round, the Ransom Note. A cheat scrap with all four rules is available at any point.

## Using it in class

- Students need only a browser and an internet connection (the fonts load from Google Fonts).
- There are no accounts. Progress is saved in the browser on that device, so a different device or browser starts afresh.

## About the project

The whole game is a single file, `index.html`, hosted with GitHub Pages from the `main` branch.
