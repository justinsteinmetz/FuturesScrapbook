# Futures Scrapbook

A collage-style grammar game on the four ways of talking about the future in English, for use in lessons.

**Play it:** https://justinsteinmetz.github.io/FuturesScrapbook/

## What it covers

There are eight scraps, plus a boss round:

1. **case files**: a discovery scrap with no rules given up front. Students work out the patterns from situations.
2. **will**: decisions made now, offers, promises and opinions
3. **going to**: earlier plans and predictions you can see coming
4. **present progressive**: fixed arrangements with a time
5. **present simple**: timetables and schedules
6. **more than one**: several forms can be right, and the choice changes the emphasis
7. **the decider**: all four forms mixed together
8. **your page**: students write their own sentences and build a page they can show their teacher

Beat every scrap to unlock the boss round, the Ransom Note. A cheat scrap with all four rules is available at any point.

## How it works

- Each form scrap has three stages: **Recognise**, **Explain** and **Use**.
- Passing a scrap earns 1 star. Mastery earns 3 stars.
- Questions students miss collect in a **Fix-it** scrap on the board, so they can have another go.
- Progress saves on the device and can be reset with the **Reset progress** button at the bottom of the board.

## Using it in class

- A full run takes roughly 50 minutes, so the boss round suits a second lesson.
- Students need only a browser and an internet connection (the fonts load from Google Fonts).
- There are no accounts. Progress is saved in the browser on that device, so a different device or browser starts afresh.

## About the project

The whole game is a single file, `index.html`, hosted with GitHub Pages from the `main` branch.
